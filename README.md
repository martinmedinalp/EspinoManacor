# EspinoManacor

Aplicación para marcar referencias y medir parámetros de balance sagital en radiografías laterales de columna.

## Abrir la aplicación

https://martinmedinalp.github.io/EspinoManacor/

También podés descargar index.html y abrirlo en tu navegador.

## Versión inicial

Incluye logo EspinoManacor, parámetros angulares, GAP score, orientación Roussouly y SVA visual opcional. El SVA visual no proporciona una distancia en milímetros sin calibración de la imagen.

## Desarrollo

La aplicación se distribuye en un único archivo index.html. Las modificaciones guardadas en main se publican mediante GitHub Pages. El historial de commits permite revisar y recuperar versiones anteriores.

## Alcance

Prototipo sin validación clínica. Revisar las referencias anatómicas y los resultados antes de cualquier uso clínico.
